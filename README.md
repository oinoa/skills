# Навыки OINOA

Навыки для ИИ-сотрудников [OINOA](https://my.oinoa.com): что сотрудник умеет делать и как. Каждый навык лежит в своей папке `skills/<навык>/`, его основной файл `SKILL.md`.

**Как добавить навык сотруднику.** В приложении OINOA откройте Настройки → Навыки, найдите навык и нажмите стрелку установки. Или в терминале сервера:

```
npx skills add oinoa/skills --skill <навык>
```

| Навык | Что делает |
|---|---|
| [business-apps](skills/business-apps/SKILL.md) | Ваши бизнес-сервисы: сделки, лиды и задачи в Битрикс24, amoCRM, HubSpot и Pipedrive, склад и заказы в МойСклад, Яндекс Календарь, Notion, Asana, Calendly и счета. Сервис подключается в Настройках → Инструменты. |
| [mail](skills/mail/SKILL.md) | Ваша почта (Gmail, Яндекс, Mail.ru, iCloud): подключение прямо в чате, поиск, чтение, ответы и письма. |
| [fin-model](skills/fin-model/SKILL.md) | Финансовая модель, смета или расчёт сделки, которые можно проверить построчно: источники, формулы, базовый и плохой сценарий. |
| [print-check](skills/print-check/SKILL.md) | Проверка упаковки, этикетки или макета перед печатью: штрихкод, текст, адреса, даты, обязательные сведения и требования типографии. |
| [site-build](skills/site-build/SKILL.md) | Лендинг или небольшой интернет-магазин от брифа до публикации, с проверкой на телефоне и публикацией только после вашего «да». |
| [turnkey](skills/turnkey/SKILL.md) | Зовёт специалиста OINOA («Настройка под ключ»), когда работа требует рук человека: подключить CRM, бота, сайт, оплату или доступы. |
| [incident-response](skills/incident-response/SKILL.md) | Ведёт сбой от первой тревоги до восстановления: уровень серьёзности, откат, спокойная связь с командой и разбор после. |
| [runbook](skills/runbook/SKILL.md) | Инструкции для сервиса и оповещения, которые срабатывают на реальную проблему пользователей, а не на шум. |
| [self-host](skills/self-host/SKILL.md) | Переезд с облачного сервиса на свой сервер: что стоит переносить, сам переезд и проверка резервных копий восстановлением. |

Персонажи и команды OINOA живут в отдельном закрытом репозитории; здесь только навыки.

# OINOA skills

Skills for OINOA's AI employees, one folder each under `skills/`. In the OINOA app: Settings → Skills. On a server: `npx skills add oinoa/skills --skill <skill>`.
